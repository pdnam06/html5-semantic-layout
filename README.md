# HTML5 Semantic Layout

Bài thực hành tạo bố cục trang web bằng các thẻ ngữ nghĩa HTML5:

- `<header>`: phần đầu trang và tiêu đề section.
- `<nav>`: thanh điều hướng.
- `<section>`: nhóm nội dung theo chủ đề.
- `<article>`: bài viết độc lập.
- `<aside>`: nội dung bổ trợ.
- `<footer>`: thông tin cuối trang.

Trang có giao diện responsive cho máy tính, tablet và điện thoại.
